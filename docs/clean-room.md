# Clean-room implementation rules

This project independently implements a product category described by public feature information. Contributors must not use proprietary source code, private API captures, leaked documents, copied visual assets, trademark-confusing branding, or pixel-identical screen reproduction.

Allowed inputs include public product descriptions, public standards, public API documentation, generally known interaction patterns, and independently written requirements. The implementation should use original naming, copy, visual language, architecture, and source code.

Any uncertain behavior is documented as a product decision rather than represented as verified behavior of another service.
